# Sam's Barbers — Demo

Cinematic one-page website for **Sam's Barbers**, 7 Hare Lane, Gloucester GL1 2BA.

> Note: service prices shown on the site are placeholders — confirm the real price list with the shop before going live.

Built with **Astro** + **GSAP ScrollTrigger** + **Lenis** smooth scroll.

## Features

- Fullscreen hero with staggered line reveal and slow parallax
- Grain overlay + custom cursor (dot & trailing ring)
- Scroll-scrubbed word-by-word manifesto reveal
- Layered editorial image grid with clip-path reveals and multi-speed parallax
- Pinned image-expansion sequence (frame grows to fullscreen on scroll)
- Price menu with cursor-following image previews
- Pinned horizontal testimonial scrub
- Respects `prefers-reduced-motion`

## Develop

```bash
npm install
npm run dev
```

## Deploy

Pushing to `main` triggers the GitHub Actions workflow which builds and deploys to GitHub Pages.
